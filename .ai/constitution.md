# Agentic Development Readiness Benchmark Constitution

Read this file once per session. If another document contradicts it, this file wins and the
other document is the defect. Amendments require a public RFC and a benchmark version change.

1. **Vendor neutrality.** Controls describe outcomes and boundaries, not preferred models or tools.
2. **Evidence over declarations.** Documentation proves documentation; enforcement needs mechanical
   evidence; measured maturity needs outcomes over time.
3. **Non-compensating safety floors.** Security, testing, governance, and rollback cannot be averaged
   away by strengths elsewhere.
4. **Local-first privacy.** Default assessment is read-only, offline, and retains no source content.
5. **Transparent scoring.** Every score exposes the controls, evidence, confidence, risks, and
   remediation that produced it.
6. **Versioned meaning.** Published benchmark versions are immutable; changes create a new version.
7. **Profiles over false universality.** Required controls reflect the autonomy being requested.
8. **No self-assessment certification.** Self-assessments distinguish repository-detected,
   agent-collected, and human-attested evidence; only a separate independently reviewed result may
   support a future certification claim.
