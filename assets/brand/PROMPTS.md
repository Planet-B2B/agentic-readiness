# Image-generation briefs

Both assets were generated with the built-in OpenAI image-generation workflow and then resized using
macOS `sips`. These briefs record the final prompts for transparent regeneration and future variants.

## Avatar

```text
Use case: logo-brand
Asset type: square avatar and application mark for an open-source developer tool
Primary request: create a distinctive geometric emblem for the Agentic Development Readiness Benchmark. Ten small connected nodes form a disciplined constellation around a central readiness compass/check shape. The mark should communicate evidence, engineering rigor, safe autonomy, measurement, and forward motion without looking defensive or bureaucratic.
Style/medium: premium vector-like brand illustration, crisp geometric construction, flat shapes with restrained subtle depth, modern enterprise developer-tool aesthetic
Composition/framing: perfectly centered square composition, strong silhouette, generous safe padding, readable at 32px, balanced radial geometry
Lighting/mood: precise, trustworthy, optimistic, technical
Color palette: deep navy background #081425; luminous teal #39D9C8; electric blue #5A8CFF; one small warm amber signal accent #FFB84D; high contrast
Constraints: exactly ten clearly intentional outer nodes; no text; no letters; no robot; no brain; no human face; no shield; no stock clip-art; no watermark; no mockup frame; keep the symbol visually simple enough for an avatar
```

## Banner

The generated avatar was provided as the visual-identity reference.

```text
Use case: ads-marketing
Asset type: wide 2:1 GitHub social-preview banner and README hero for the same open-source developer tool
Input images: Image 1 is the approved avatar mark and the exact visual identity to reuse faithfully
Primary request: build a polished wide banner for the Agentic Development Readiness Benchmark. Place a simplified faithful version of the supplied ten-node compass/check emblem on the left, and the project title and subtitle on the right. Extend a subtle constellation/evidence grid across the background so the visual suggests measured engineering systems, bounded autonomy, and trustworthy progress.
Style/medium: premium vector-like brand illustration, crisp geometric enterprise developer-tool design, clean and restrained, not sci-fi fantasy
Composition/framing: exact wide 2:1 composition, emblem occupies left 34 percent, text occupies right 58 percent, generous margins and strong hierarchy, safe area suitable for GitHub social preview cropping
Lighting/mood: precise, trustworthy, optimistic, technical
Color palette: deep navy #081425 background with subtle navy gradient; luminous teal #39D9C8; electric blue #5A8CFF; small amber #FFB84D signal accent; white and pale blue typography
Text (verbatim): "Agentic Development Readiness"
Subtitle text (verbatim): "Evidence-backed benchmark for AI engineering harnesses"
Typography: modern geometric sans serif, title bold and large on two lines maximum, subtitle smaller and highly legible
Constraints: preserve the core supplied emblem; exactly ten intentional outer nodes when visible; render both text strings verbatim with correct spelling and capitalization; no other words; no robot; no brain; no face; no shield; no code screenshots; no stock clip-art; no watermark; no mockup frame; keep all important content comfortably inside the canvas
```
