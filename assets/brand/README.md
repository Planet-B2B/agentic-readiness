# Brand assets

The mark combines ten connected nodes—one per benchmark dimension—with a readiness compass/check.
It represents measured progress, evidence, bounded autonomy, and engineering systems working together.

## Files

| Asset        |     Size | Intended use                                                              |
| ------------ | -------: | ------------------------------------------------------------------------- |
| `avatar.png` |  512×512 | Project avatar, package profile, favicon source, and square social use    |
| `banner.png` | 1280×640 | GitHub social preview, README hero, release announcements, and link cards |

## Palette

- Deep navy: `#081425`
- Luminous teal: `#39D9C8`
- Electric blue: `#5A8CFF`
- Signal amber: `#FFB84D`

Keep the avatar's safe padding, ten-node structure, colors, and central readiness motif intact. Do not
use the mark as a certification seal or imply independent verification. The assets are distributed
under the repository's Apache-2.0 license.

The image-generation briefs are recorded in [PROMPTS.md](PROMPTS.md).
